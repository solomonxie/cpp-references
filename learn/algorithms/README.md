# C++ Algorithms & Patterns

This directory contains clean, template-like implementations of essential algorithms and LeetCode patterns following the NeetCode roadmap.

- [0001_bubble_sort.cpp](0001_bubble_sort.cpp) - O(n^2) stable sort.
- [0002_selection_sort.cpp](0002_selection_sort.cpp) - O(n^2) simple sort.
- [0003_insertion_sort.cpp](0003_insertion_sort.cpp) - O(n^2) online sort.
- [0004_merge_sort.cpp](0004_merge_sort.cpp) - O(n*logn) stable divide-and-conquer.
- [0005_quick_sort.cpp](0005_quick_sort.cpp) - O(n*logn) average case in-place sort.
